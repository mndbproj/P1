Iran SOCKS proxy feed

Auto-refreshed by GitHub Actions. Two subscription links, always pointing at the latest data:

  • proxies.json — full JSON, one object per working proxy
  • socks.txt — plain text, one protocol://ip:port per line
  • meta.json — last-updated time and counts

Use it from Python:

import requests

url = "https://YOUR_USERNAME.github.io/YOUR_REPO/proxies.json"
proxies = requests.get(url, timeout=10).json()
p = proxies[0]
proxy_url = f"{p['protocol']}://{p['ip']}:{p['port']}"

r = requests.get("https://httpbin.org/ip",
                  proxies={"http": proxy_url, "https": proxy_url},
                  timeout=8)
print(r.json())
